# Telegram Bot Username Sales

A monorepo containing the Telegram Bot and Web Management System for the Telegram Username Sales platform.

## Project Structure

```text
telegram-bot-username-sales/
├── bot/
├── web/
├── deploy/
├── docs/
│   ├── PROJECT_SPEC.md
│   └── PROMPTS.md
├── README.md
├── LICENSE
└── .gitignore
```

## Components

* **bot/** — Telegram Bot application
* **web/** — Web management interface
* **deploy/** — Copies of the production systemd service files (`buytelegrambots-web`, `gram-bid-system`)
* **docs/** — Project documentation

> Documentation is under active development for further improvement.
